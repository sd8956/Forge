## Findings and fixes

1. **A fresh dependency branch counted as merged.** `git merge-base --is-ancestor feat/TASK-x main` is true for a
   branch with no commits. A dependency Forge ran now counts as merged only when its latest run is `done`. This
   also affected `forge run-task` (`9b76900`).
2. **The evidence tab emptied after a merge.** Merging removes the worktree; `/runs/:id/evidence` now reads the
   archived handoffs (`caf139d`).
3. **Three permission prompts, none of them file reads** (found in the transcripts, since allowed `PreToolUse`
   calls are not recorded):
   - `EVIDENCE_DIR=.factory/runs/TASK-005/e2e/1/evidence npx playwright test e2e/escape.spec.js` (e2e): a variable in
     front of the command does not match `Bash(npx playwright test:*)`. The guard now denies `NAME=value cmd` with a
     hint to use `make e2e EVIDENCE_DIR=...`.
   - `gh pr list --head feat/TASK-005 --state open ...` (pr): now allowed (read-only).
   - `make e2e EVIDENCE_DIR=/tmp/claude-1000/e2e-ev` (development): `make e2e` is now allowed in development, and the
     guard checks `NAME=/path` and `--flag=/path` values against the worktree (`34dd8b0`, `8e2bc2b`).
   The person asked whether steps could run in `auto` mode; they keep `--permission-mode` from the agent
   (`CLAUDE.md`: steps never run with `bypassPermissions` or `auto`).
